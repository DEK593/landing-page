# landing-page

Landing Page Project
A responsive landing page built as part of The Odin Project foundations course, featuring a custom wildlife and nature theme.

Features
Header Navigation: Custom brand logo and navigation links.

Hero Section: Main title, descriptive subtitle, sign-up button, and primary hero image layout.

Wildlife Information Cards: A flexible grid section built using CSS Flexbox to showcase different animals (fish, koala, wolf) with descriptions and optimized image scaling.

Quote Section: A dedicated testimonial area featuring distinct background styling and typography.

Call to Action Section: A structured signup banner highlighting secondary actions.

Technologies Used
HTML5: Semantic markup structure.

CSS3: Custom styling, layout design using Flexbox, responsive properties, and asset positioning (object-fit).

Git & GitHub: Version control and remote repository management.
